# CoWork

A full-stack freelance marketplace connecting clients who post jobs with freelancers who apply, get hired, and deliver work through a milestone-based system.

## Tech Stack

- **Frontend:** React (Vite)
- **Backend:** Node.js, Express
- **Database:** MongoDB (Mongoose)
- **Auth:** JWT (access + refresh tokens)

## Status

🚧 In active development — currently building out backend authentication and core features.

## Project Structure

```
cowork/
├── server/     # Express backend API
└── client/     # React frontend (coming soon)
```
